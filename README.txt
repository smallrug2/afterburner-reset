Afterburner Profile Resetter (Windows) (afterburner_reset.py)
========================================
Coded by: Muse Spark (Meta AI assistant)
Curated by: smallrug2
License: MIT (see LICENSE file)

WHAT IT DOES:
Rewrites an MSI Afterburner .cfg with stock + safe-OC profiles. Backs up the original. Never touches voltage.

REQUIREMENTS:
Python 3.8+ only - no extra packages needed (stdlib only).

HOW TO RUN:
python afterburner_reset.py --help
python afterburner_reset.py --profile "C:\Profiles\card.cfg"

PLATFORM:
WINDOWS ONLY (refuses to run elsewhere).
